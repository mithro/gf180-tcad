# TCAD jobs that .github/workflows/crosscheck.yml (job crosscheck-tcad) and `make reproduce-quick`
# regenerate with tools/crosscheck-tcad-run into a temporary tree root and compare byte for byte
# with results/MANIFEST.sha256
# (python -m gf180tcad.manifest verify-subset --kind tcad --prefix tcad/).
#
# One job per line, <tree>/<device>/<params>, <tree> in {moscap1d, moscap2d, meshes/stable} and
# <params> in {start, calibrated}. Each moscap1d job reruns exactly the committed configuration:
# the selected mesh (results/tcad/meshconv/moscap1d/<device>/selected.json), the SPICE cv gate
# biases and the committed calibrated values (results/tcad/calibration/<device>.json). Each
# meshes/stable job cuts every committed reduced mesh artefact of the device's calibrated 2D
# cells again, from the full meshes pulled from the output cache. A tree's provenance.json is
# compared too; it lists the calibration of every calibrated job in the tree, so both devices
# are listed for each tree to match the committed one.
